# Logistic Regression Sentiment Classifier

A logistic regression sentiment classifier implemented from scratch in Python. The project uses stochastic gradient descent to classify positive and negative text and supports TF-IDF features, L2 regularization, lazy regularization, and configurable learning rates.

## Usage

```bash
python logreg.py
```

Optional arguments can configure the training step size, number of passes, regularization, input files, and extra-credit modes.
